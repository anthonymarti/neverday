# Brand and product

Name retained: Neverday, Neverday.com. Tagline: Go a little further.

Warm paper #f7f5ee; ink green #192a24; burnt orange #c6421c. Georgia headlines suggest a travel notebook; system sans-serif controls need no font purchase. Original orbital line art and travel-pass motif avoid stock/licensed imagery.

Calm, practical language. No invented testimonials, partner logos, coverage claims or unlimited-data promises. Simulation status appears in the persistent banner and at important steps.

Mobbin inline previews actually inspected:
- https://mobbin.com/flows/a9641df8-8072-4e49-9b99-1df4f0c9c10a — Airalo package details, including compatibility, validity/activation, routing and top-up explanations.
- https://mobbin.com/flows/6d0b7f6e-9c1b-4046-b410-04982409a380 — Airalo purchase previews, including selected pack, payment choices and post-purchase install guidance.

Only returned previews were inspected, not every full-resolution screen. Those information priorities informed an original interface. No Mobbin image is shipped.

Accessibility intent: labels, required native controls, fieldset/legend, skip link, landmarks, focus styles, alert/status regions, native reset dialog and reduced-motion support. Verify actual contrast/focus/screen-reader behavior; automated journey checks alone do not prove WCAG conformance.

Final lead demo pack: Japan5GB/30days at an independently chosen sample $11. It serves the proposed7–15day trip while matching a public supplier-listed duration. Extra validity is not an auto-renewal; actual activation/expiry still depends on contracted SKU rules. No live partnership claim is introduced.
